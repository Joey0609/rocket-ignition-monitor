## 评价口径

发动机底部初始火光、亮芯，或可归因于发动机点火的局部照亮首次可见，就视为点火已发生；不等待大面积尾焰外露或火箭离架。人工以原拼接视频 852×480、10 FPS 的相邻画面复核。时间只是离线评估参考，线上仍在当前画面确认，不回溯补发。

这是单人视觉标注，不是发动机遥测真值；表中的 0.1–0.2 秒范围表示采样画面中可辨视觉变化的区间，不能理解为物理点火时间达到相同时间精度。

## 迟报原因

1. 旧 ROI 的下边界是画面高度 83%。这几场初始发动机火光主要位于约 85%–93% 高度，一部分早期证据落在 ROI 外。
2. 320×180 缩图和 3×3 形态学开运算会丢掉小火光，宽区域面积归一化及较高确认阈值也偏向较大的火焰。
3. 暖色条件会忽略早期白色亮芯；现有灯光排除会抑制原亮区附近的新火光。
4. 弱候选的固定等待超时可能在强证据刚开始增强时取消候选并进入冷却，继续增加等待。

这些是根据实现和逐帧证据定位的原因，不表示每一项的独立贡献均已做消融验证。

## 修正规则的失败诊断

本轮尝试了原尺寸局部发动机区域、较小连通域、夜间白色亮芯和 3/4 帧快速确认。短片中长征十二号的一个试验配置可提前到初始火光后约 0.2–0.4 秒，但将更敏感规则放回发射前录像后，两种试验配置分别在片头 17.8 秒、63.3 秒出现错误确认，画面没有发动机点火。

该长回放尝试在确认失败后停止，**没有完整跑完，不能标为全量验证成功**；试验规则未替换线上 V3。因此不能宣称“已经修好”或“早检且零误报”。正式报告采用上表可复核的 V3 完整回放结果，失败试验只作为诊断。
